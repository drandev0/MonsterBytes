# Monster Bytes: the Endless Ages guide

Every monster, weapon, armor piece, spell, recipe, quest, map and item in
Endless Ages, one Markdown file each in [`content/`](content/). It started
from plasticAiredale's 2010 program EA Monster Bytes and is kept up to date by
players.

**Want to fix a number or add something?** See [CONTRIBUTING.md](CONTRIBUTING.md).
You can do it all on github.com; nothing to install.

Merged changes appear on the site within a minute.

| Folder | Holds |
|---|---|
| `content/` | The guide: one file per entry |
| `public/mb/` | Pictures, element icons and the original program's art |
| `scripts/` | The checker that runs on every pull request (`npm run check`) |
